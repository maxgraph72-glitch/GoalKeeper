# Структура экранов MVP

Статус: рабочая версия, согласованная для прототипирования. Решения можно корректировать после проверки wireframe.

## Навигация

Постоянная основная навигация содержит три раздела:

- **Сегодня** — стартовый экран;
- **Цели** — активные цели;
- **Архив** — завершённые и архивированные цели.

Действие **«Новая цель»** доступно из основной навигации и экрана целей.

## Сегодня

Экран содержит незавершённые шаги с датой:

1. просроченные;
2. запланированные на текущую дату.

Шаг можно завершить прямо на экране. Каждый шаг показывает связанную цель, этап и срок.

Шаги без даты на этом экране не отображаются. Отдельное ручное планирование «на сегодня» не входит в MVP.

## Цели

Экран показывает активные цели в виде карточек. Карточка содержит:

- название и категорию;
- вычисляемый прогресс;
- ближайший незавершённый шаг;
- целевую дату.

Доступны поиск, фильтр по категории и сортировка. Выбор карточки открывает страницу цели.

## Страница цели

Верхняя часть содержит название, описание, категорию, целевую дату, статус и вычисляемый прогресс.

Основная часть содержит упорядоченные этапы и шаги. Этапы и шаги можно создавать, редактировать, удалять и переупорядочивать. Шаги можно завершать и открывать снова.

Для простой цели интерфейс автоматически создаёт этап **«Основное»**, чтобы пользователь мог сразу добавлять шаги.

Выполнение всех шагов доводит прогресс до 100%, но не завершает цель автоматически. Пользователь подтверждает достижение цели отдельным действием.

## Архив

Экран разделён на две вкладки:

- **Завершённые**;
- **Архивированные**.

Завершённую цель можно открыть снова, архивированную — восстановить. Постоянное удаление является отдельным действием и требует подтверждения.

## Диалоги

- **Новая цель / редактирование цели:** название, описание, категория, целевая дата и цвет.
- **Новый этап / редактирование этапа:** название.
- **Новый шаг / редактирование шага:** название и необязательный срок.
- **Подтверждение удаления:** конкретно сообщает, какие данные будут удалены.

Создание цели не требует немедленно заполнять этапы и шаги. После сохранения открывается страница новой цели.
